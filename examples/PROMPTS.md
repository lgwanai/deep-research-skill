# 案例指令

以下内容均为可直接提交给 Agent 的指令，不包含结果。

## 1. 最新功能核验

```text
使用 $deep-research-agent，以 Quick 模式核验 OpenAI Codex 当前是否支持指定功能。请优先读取官方文档和发布说明，给出明确的信息截止日期，区分正式可用、测试版和仅公告未上线状态，并为所有时间敏感结论提供引用。
```

## 2. 产品选型比较

```text
使用 $deep-research-agent，以 Standard 模式比较 Cursor、Claude Code 和 Codex 在大型 TypeScript 单体仓库中的适用性。重点比较代码理解、跨文件修改、测试与终端能力、权限控制、价格、上下文限制和团队协作。使用截至今天的公开信息，按不同团队场景给出选择建议，不要给出脱离使用场景的绝对排名。
```

## 3. 中国行业研究

```text
使用 $deep-research-agent，以 Pro 模式研究中国工业机器人行业，信息截止日为今天。使用中英文检索，明确市场边界，分析市场规模及口径差异、产业链、利润池、需求驱动、主要厂商、国产替代、政策、技术约束和未来三年风险。输出行业专家简报，并附证据与检索审计附录。
```

## 4. 海外市场进入研究

```text
使用 $deep-research-agent，以 Pro 模式研究一家中国储能设备企业进入德国工商业储能市场的可行性。覆盖市场定义、目标客户、认证和监管、渠道结构、主要竞争者、价格与项目经济性、并网和供应链约束。输出进入策略、优先客户类型、主要风险、验证清单和停止条件。
```

## 5. 公司尽调

```text
使用 $deep-research-agent，对指定公司开展 Pro 级公司尽调。分析法律实体、业务模式、产品与客户、收入质量、成本结构、三到五年财务趋势、现金流、债务、客户集中度、关联交易、诉讼和治理风险。优先使用审计报告、监管文件和公司公告，输出公司尽调备忘录，并列出仍需管理层回答的问题。
```

## 6. A 股基本面与估值

```text
使用 $deep-research-agent 和证券研究专家，以 2025-12-31 为严格信息截止日，对一家指定 A 股公司进行基本面与估值研究。只能使用该日期之前可获得的信息，优先使用巨潮资讯和交易所公告。核对股票代码、股本、复权事项、增发回购、会计口径和合并范围，建立熊市、基准和牛市估值情景，展示关键公式和原始输入，并说明什么证据会改变结论。
```

## 7. 港股与 ADR 比较

```text
使用 $deep-research-agent，比较同一家公司的港股普通股和美股 ADR。确认证券代码、ADR 换算比例、币种、价格时间戳、流通性、股本和企业价值口径，分析估值差异来自汇率、交易时间、流动性、投资者结构还是基本面。输出证券比较报告，不要直接比较未经换算的每股价格。
```

## 8. 财报前瞻

```text
使用 $deep-research-agent，为指定上市公司制作下一季度财报前瞻。明确财报发布时间、市场一致预期的时间戳、管理层指引和历史口径，识别最可能改变盈利预测和估值的三个指标，区分价格、销量、产品结构、汇率和一次性因素，并给出财报后的判断更新规则。
```

## 9. 财报点评

```text
使用 $deep-research-agent，对指定公司刚发布的财报进行点评。对比实际值、前期指引和发布前一致预期，区分 reported、adjusted 和 Agent 自行估算的数据，分析收入质量、利润率、现金流、营运资本和一次性项目，更新基本面判断、估值输入、催化剂和风险。输出财报点评，不提供个性化投资建议。
```

## 10. 宏观政策影响

```text
使用 $deep-research-agent，以 Pro 模式研究某项货币或财政政策对指定行业和资产的影响。使用央行、统计机构、政府文件和正式实施细则，区分政策公告与实际执行，保留数据发布时间和修订版本，构建政策到利率、汇率、需求、成本和企业盈利的传导链，并输出基准、上行和下行情景。
```

## 11. AI 技术产品评估

```text
使用 $deep-research-agent，评估两个指定 AI 模型或开发工具在企业生产环境中的适用性。核对当前版本、官方文档、价格、速率限制、上下文窗口、数据处理、安全合规、部署方式和状态页，审查第三方基准的方法和可复现性，并结合 GitHub issue 或用户反馈识别实际故障模式。输出技术产品评估报告。
```

## 12. 开源项目研究

```text
使用 $deep-research-agent，研究指定 GitHub 开源项目是否适合纳入核心生产系统。检查官方文档、发布节奏、贡献者集中度、未解决 issue、安全公告、许可证、兼容性、测试和迁移成本。区分仓库活跃度与真实生产成熟度，输出采用建议、风险和试点验证计划。
```

## 13. 医疗疗法比较

```text
使用 $deep-research-agent 和医疗生命科学专家，比较两种指定疗法在特定适应症和患者人群中的疗效、安全性、监管状态和指南位置。优先使用监管机构、试验注册、药品标签、指南和同行评议论文，严格对齐试验设计、样本、比较组、终点和随访时间，不把跨试验比较表述为头对头证据，不提供个性化医疗建议。
```

## 14. 能源商品研究

```text
使用 $deep-research-agent，以 Pro 模式研究指定能源商品未来十二个月的供需与价格风险。明确地区、交割点、单位和时间范围，分析产量、需求、库存、运输、边际成本、期货结构、政策和天气因素，严格区分物理市场数据、金融价格、机构预测和 Agent 情景假设。输出能源商品简报。
```

## 15. 社交媒体用户研究

```text
使用 $deep-research-agent，结合小红书、B站、Reddit 和公开网页研究指定消费产品的真实用户抱怨与购买阻力。执行工具能力审计，优先使用可用的平台原生或 Agent Reach 能力。将社交内容作为定性信号，说明样本偏差，不把帖子数量外推为总体发生率，并使用官方资料核验产品能力和安全相关事实。
```

## 16. 市场规模冲突核验

```text
使用 $deep-research-agent，核验两份报告对同一市场给出的冲突规模数字。追溯原始报告、数据集和方法说明，对齐市场边界、地区、年份、收入或出货口径、名义或实际价格、汇率和预测方法。如果无法统一，保留两个数字并说明差异如何影响决策，不要简单选择更新的数字或取平均值。
```

## 17. 付费墙来源追溯

```text
使用 $deep-research-agent，核验一篇付费媒体文章中引用的关键统计数据。不要假装读取无法访问的正文，尝试追溯其公开原始报告、监管文件、数据集或发布机构。只引用实际读取和验证的内容，并明确说明仍受付费墙限制的部分。
```

## 18. Ultra 多工作流研究

```text
使用 $deep-research-agent，以 Ultra 模式研究指定新兴行业的全球格局与中国机会。按市场与需求、技术与供应链、公司与竞争、资本市场、政策监管五个独立工作流推进，建立实体和证据来源关系，进行交叉工作流口径校准、反方检索和结论收敛。输出完整报告、证据审计附录和可复现 JSON 研究包，并运行严格校验。
```

## 19. 风险监控

```text
使用 $deep-research-agent，为指定上市公司建立未来六个月风险监控框架。将风险转化为可观察信号、阈值、数据来源、检查频率和触发后的观点变化，覆盖基本面、财务、治理、监管、流动性、汇率利率、商品价格和再融资风险。输出证券风险监控表。
```

## 20. 可复现审计研究

```text
使用 $deep-research-agent，对指定问题执行 Pro 级可审计研究。除主报告外，同时导出 JSON 研究包，包含研究合同、信息截止日、工具能力概况、问题分支、来源及独立 origin、原子化 claim、计算输入与公式、覆盖矩阵、检索日志、冲突、缺口、停止原因和最终置信度。完成后运行 validate_research_package.py --strict，并在主结论中披露所有决策关键缺口。
```
