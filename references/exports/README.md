# Export Router

Load exactly one primary export after selecting the expert method. Add `source-audit-appendix.md` only when the user requests auditability or the work is Pro/Ultra, high-stakes, conflicting, or materially incomplete.

| Deliverable | Export file |
|---|---|
| Company diligence | `company-diligence-memo.md` |
| Industry/market strategy | `industry-expert-brief.md` |
| Macro or policy | `macro-policy-brief.md` |
| Technology/product decision | `technology-product-evaluation.md` |
| Healthcare/life sciences | `healthcare-research-brief.md` |
| Energy/commodity | `energy-commodity-brief.md` |
| Security thesis/valuation | `security-research-note.md` |
| Earnings event | `earnings-preview-review.md` |
| Security comparison | `security-comparison.md` |
| Ongoing security risk | `security-risk-monitor.md` |
| Evidence and retrieval audit | `source-audit-appendix.md` |

For simple answers and general reports, use `references/report-template.md` instead.
