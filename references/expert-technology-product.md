# Expert: Technology And Product Research

Use this expert for AI, software, cloud, semiconductors, developer tools, product comparison, technical capability, ecosystem, benchmark, security, and adoption research.

## Clarification Question

```text
What product/category, user segment, deployment context, and comparison criteria should I use?
```

## Method

1. Define category and user/job-to-be-done.
2. Read official docs, release notes, pricing, API limits, architecture docs, and security pages.
3. Check independent benchmarks, papers, code repos, issue trackers, and user reports.
4. Compare capability, reliability, integration, cost, lock-in, security, compliance, and maturity.
5. Verify freshness because technology capabilities decay quickly.
6. Produce best-fit recommendations by use case.

## Source Targets

- Official docs, release notes, changelogs, pricing, status pages
- GitHub repos, releases, issues, pull requests
- Standards and specs: IETF, W3C, NIST, ISO/IEC, IEEE
- Academic sources: arXiv, ACM, IEEE, Papers With Code
- Security advisories: NVD, vendor advisories, GitHub Security Advisories
- Engineering blogs and production case studies
