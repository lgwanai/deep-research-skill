# 使用说明

Deep Research Agent 是一个研究协议型 Skill。它不会绑定单一搜索服务，而是根据宿主当前具备的搜索、网页读取、浏览器、社交平台、金融数据和文件处理能力动态选择工具。

## 1. 安装

将项目目录复制或软链接到 Agent 宿主的 Skill 目录，并保持目录名为 `deep-research-agent`。

Codex 示例：

```bash
cp -R /path/to/DeepResearch ~/.codex/skills/deep-research-agent
```

如果使用其他支持 Skill 的 Agent，请将项目安装到该宿主约定的 Skill 目录。

## 2. 调用方式

### 显式调用

在指令中直接使用 Skill 名称：

```text
使用 $deep-research-agent 调研……
```

显式调用适合需要确定启用深度研究流程、专家模式或审计输出的任务。

### 自动调用

当请求包含最新信息、多来源验证、行业研究、证券分析、产品比较或外部事实核验时，支持自动发现 Skill 的宿主可以自动加载它。

## 3. 如何写研究指令

高质量指令建议包含以下信息：

| 信息 | 说明 | 示例 |
|---|---|---|
| 研究对象 | 公司、行业、产品、政策或证券 | 中国工业机器人行业 |
| 决策目标 | 研究用于什么决策 | 判断是否值得进入该市场 |
| 地理范围 | 全球、国家、地区或交易市场 | 中国大陆 |
| 时间范围 | 历史区间、预测期或信息截止日 | 截至 2026-09-22 |
| 研究深度 | Quick、Standard、Pro 或 Ultra | Pro |
| 重点问题 | 必须回答的关键问题 | 市场规模、产业链、竞争格局 |
| 输出格式 | 简报、研报、比较表或审计包 | 行业专家简报 |
| 限制条件 | 排除项、语言、来源偏好 | 中英文检索，优先官方来源 |

不需要一次提供全部信息。缺少的信息会显著改变研究设计时，Skill 最多询问一个紧凑问题；否则会声明合理假设后继续。

## 4. 研究深度

| 模式 | 适用任务 | 典型要求 |
|---|---|---|
| Quick | 单一事实、发布日期、功能状态 | 读取权威页面并引用 |
| Standard | 主题概览、产品比较、近期变化 | 多角度检索、关键来源、风险和未知项 |
| Pro | 行业报告、公司尽调、证券研究 | 问题树、研究队列、证据账本、结论验证 |
| Ultra | 多实体、高风险、复杂战略研究 | 独立工作流、反方检查、收敛审查、可复现研究包 |

如果没有指定模式，Skill 会选择能够满足任务的最小模式。

## 5. 专家模式

Skill 会根据请求自动选择一个主要专家，并在确有必要时加载不超过两个辅助专家：

- 股票、ETF、债券、估值和财报：证券研究专家
- 商业模式、财务报表和尽调：公司财务专家
- 市场规模、产业链和竞争格局：行业研究专家
- 利率、通胀、汇率和政策传导：宏观政策专家
- AI、软件、云、半导体和产品比较：技术产品专家
- 药物、器械、临床试验和审批：医疗生命科学专家
- 油气、电力、新能源、矿业和碳市场：能源商品专家

股票证券任务会额外执行信息截止日、价格时间戳、股本变化、会计口径、估值复算和风险检查。

## 6. 检索工具策略

执行外部研究前，Skill 会检查宿主中实际可用的能力：

- 专用搜索服务或 Agent Reach
- 网页读取和官方 API
- 渲染浏览器和自动化浏览器
- 社交媒体、视频、论坛和代码平台工具
- 金融行情和证券数据工具
- 爬虫、文档转换和结构化提取工具

本地环境可以运行：

```bash
python3 scripts/detect_retrieval_capabilities.py
```

该脚本只检测本地 CLI 和 Skill，不发起网络请求，也不读取凭据。宿主内置工具和 MCP 仍需要 Agent 根据当前工具列表补充判断。

## 7. 输出格式

可以在指令中直接指定交付物：

- 简短结论
- 完整研究报告
- 行业专家简报
- 公司尽调备忘录
- 股票证券研究报告
- 财报前瞻或财报点评
- 证券比较报告
- 风险监控表
- 宏观政策简报
- 技术产品评估
- 医疗研究简报
- 能源商品简报
- 证据与检索审计附录

未指定时，Skill 会选择满足任务所需的最小输出格式。

## 8. 可复现研究包

对于 Pro、Ultra 或需要审计的任务，可以要求同时导出机器可读研究包：

```text
同时导出 JSON 研究包，包含研究合同、问题分支、来源、原子化结论、计算过程、覆盖状态、检索日志和最终置信度，并运行严格校验。
```

验证命令：

```bash
python3 scripts/validate_research_package.py research-package.json --strict
```

## 9. 权威来源注册表

按领域和地区查询内置权威来源：

```bash
python3 scripts/query_source_registry.py --domain equity --region CN
python3 scripts/query_source_registry.py --domain healthcare --authority primary
```

注册表用于发现高价值来源，不代表白名单。最终仍需验证来源身份、日期、方法、口径和具体结论支持关系。
